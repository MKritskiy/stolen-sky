# Дело №20: Похищенное небо

Статический мобильный квест для подарка Ангелине. Для запуска достаточно открыть `index.html` или поднять любой статический сервер.

## Игровая последовательность

1. Четыре интерактивные загадки на сайте, ответы: `7`, `1`, `3`, `4`.
    - **Улика 01 (Облако точек).** Облако частиц на canvas с ручной 3D-проекцией; вращая пальцем, нужно найти единственный ракурс, с которого точки складываются в цифру `7`. Решение — вернуть поворот в «лицо» (rotX≈0, rotY≈0).
- **Улика 02 (Маршрутный журнал).** Журнал диспетчера с четырьмя рейсами; три показания очевидцев вразброс задают очерёдность вылета. Из «между Казанью и Сочи ровно два рейса» → они на краях; «Казань раньше Самары», «Самара раньше Москвы» → порядок: Казань → Самара → Москва → Сочи. Карточки перемешаны визуально. Нужно кликнуть рейс, ушедший третьим — это Москва №401, его последняя цифра `1`.
- **Улика 03 (Приборная панель).** Цветовой код на чётности (XOR). 4 тумблера, каждый зажигает 2 цвета: Радио→зелёная+жёлтая, Шасси→красная+жёлтая, Ток→зелёная+красная, Связь→жёлтая. Синюю не зажигает ни один тумблер. Штурвал-селектор (4 позиции З/Ж/К/С) добавляет +1 к выбранному цвету. Лампа горит, если число «указателей» на неё нечётно, гаснет при чётном. Цель: зажечь зелёную+жёлтую+синюю, красную погасить. Решение: включить только Радио (или только Шасси+Ток) и поставить штурвал на синюю → отметка `3`.
    - **Улика 04 (Снос ветром).** Самолёт держал курс на Север, ветер с Запада равен тяге по силе. Равные перпендикулярные силы дают угол 45°; пользователь перетаскивает стрелку компаса к истинному пути (45°), первая цифра угла — `4`.
 2. Код `7134` открывает отдельную коробочку с ключом.
3. Ключ открывает **второй уровень** шкатулки — там миньоны и бумажная шифровка.
4. На бумажке напечатано: `15 · 6 · 2 · 16` и подпись `А1Я33`.
5. Подпись `А1Я33` = «А первая, Я тридцать третья» (значит Ё идёт сразу после Е, всего 33 буквы). Числа переводятся в `НЕБО` (15 = Н, 6 = Е, 2 = Б, 16 = О).
6. Слово `НЕБО` вводится на сайте → показывается финальный код `2607` для замка на папке.

Каждая загадка и шифр снабжены кнопкой «Подсказка» с тремя уровнями наводки — от лёгкого намёка до прямого ответа.

Прогресс сохраняется в `localStorage` (ключ `case20_progress`): при перезагрузке уже разгаданные улики остаются решёнными, а нужный этап (расследование / чекпойнт / финал) открывается сразу. Кнопка «сбросить прогресс» в верхней панели начинает квест заново.

## Локальный запуск

```bash
python3 -m http.server 8080
```

Затем открыть `http://localhost:8080`. Для QR-кода сайт потребуется разместить на статическом хостинге с HTTPS (GitHub Pages, Netlify, Cloudflare Pages и т.п.).
